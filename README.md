#Abstraction

Abstraction is when the code hides unnecessary details from the user and shows only important features to them. 
I made this project because projects with abstraction help people to understand codes more easily and makes codes simpler.

By using abstraction, i learned that using it makes code simpler and easier to understand. It organizes codes and removes complex information.
